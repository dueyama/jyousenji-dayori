# Q&Aの内容と参照元

## 公式サイトの仏事・お経本案内

2026年10月25日、利用者の指定により、[浄泉寺公式ページ「お経本・仏事について」](https://sites.google.com/view/hitomarujyousenji/about/faq)の内容を本PWAへ追加した。既存のGoogle Sites自体は編集しない。内容の追加と公開操作は分離し、公開は利用者の明示承認後に行う。公開しても通知は自動送信しない。

- `/faq/` は質問一覧。法名・院号を先頭にし、仏事の作法・お経本・通知設定へ案内する。
- `/faq/buddhist-practices/` は本願寺派の仏事・行事Q&Aと、元ページ掲載の焼香・合掌礼拝・念珠の公式動画へのリンクを置く。
- `/faq/sutra-books/` は浄泉寺で使う「浄土真宗本願寺派 日常勤行聖典」（本願寺出版社）と「仏事勤行聖典」（百華苑）の用途・持参・寺院での用意を案内する。
- 動画はYouTubeへの通常リンクとし、埋込み・自動再生を追加しない。元ページで確認できない作法の細則は創作しない。
- お経本の表紙2点は利用者から提供された画像を使用し、`src/assets/faq/` に保存する。長辺600px以内へ縮小し、EXIF等を除去する。JPEGは元写真の軽量版、`-transparent.webp` は縁を透明化した表示用。透明化には内蔵ImageGenで得たアルファマスクだけを用い、RGBは元写真を使用する（縮小・圧縮前のRGB一致を検査）。表紙の文字を生成画像へ置き換えない。Astroで表示幅に合わせたWebPを生成し、外部の画像へ直リンクせず、仮画像で代用しない。
- 元ページの本願寺出版社の商品URL2件はHTTP 404、法藏館の商品URLはHTTP 503で、現在の商品案内を検証できなかった。そのまま購入先リンクとして転載せず、浄泉寺への相談と元の公式案内へ誘導する。価格・在庫は掲載しない。商品リンクを追加する場合は、書名・出版社・版とリンク先を再確認する。
- 2つの詳細ページはサイトマップへ登録し、BaseLayoutと共通のQ&A回答用レイアウトを使う。既存の法名・院号、通知設定、ホーム画面追加のURLは変えない。

## 検査

- `tests/faq.test.mjs` で質問一覧の順序、参照先、動画の埋込み禁止、お経本の主要文言とサイトマップ登録を検査する。
- 本番base pathでビルドし、Q&Aからの詳細リンク・戻るリンク・画像がある場合の公開パスを確認する。
- 320・375・390pxとデスクトップで文字の折り返し・タップ領域・横はみ出しを確認する。
